**Midnight Vault** — an original top-down stealth heist game that runs entirely from static files in a desktop browser. Plan the job on a live blueprint (patrol loops, cameras, lasers, loot, three entry points) and spend 6 prep points on tools — a lockpick kit, EMP charges, smoke bombs, soft soles, a duffel bag. Then run it: sneak the gallery under sweeping guard cones and camera eyes, cross timed laser beams, steal the keycard from the counting room, crack the vault's 3-tumbler timing dial while standing exposed, fill your bag with 14 weighted loot items (a heavy bag slows you down), take the Star Diamond, and reach the getaway van. Every sighting feeds one ALARM meter; at 100% the bank locks down and you have 45 seconds to escape while every guard hunts you. Score is loot × a 1.5 ghost multiplier if you were never chased, plus a speed bonus, across 8 possible ending titles. All sound is synthesized live with WebAudio — zero network, zero assets, no build step.

## Run it

```sh
node serve.ts        # then open http://localhost:8077/
# or serve the game/ folder with any static file server and open index.html
```
